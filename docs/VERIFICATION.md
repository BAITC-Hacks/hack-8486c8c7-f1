# Проверка MVP

Проверено 23 сентября 2026 года на Windows, Python 3.12 и Node.js.

## Автоматически

**19 тестов прошли** (pytest), production-сборка React/Vite прошла.

Проверены:
- точные веса 20/20/15/15/10/10/10 и нулевые баллы до подтверждения;
- четыре уровня и снижение рейтинга при удалении сведений;
- исходные 5 задач, 5 команд и 5 откликов;
- публикация задачи с 0 баллов и доступность её студентам;
- несколько откликов от одной команды без искусственного лимита;
- полный путь до ручного выбора нескольких команд;
- одноразовые награды, отсутствие повторного начисления после повторного заполнения;
- XP только после подтверждения этапа выбранной команды;
- отсутствие повторного XP через несколько откликов одной команды на ту же задачу;
- покупки и коробки не меняют readiness; повторные покупки и нехватка монет;
- ошибки ролей, невалидные URL, несуществующие записи, конфликт версий;
- корректный OpenAI-ответ, неверный JSON, неполная схема, отказ, incomplete, некорректная форма ответа, таймаут.

Есть одно предупреждение зависимости Starlette о будущем переходе TestClient с httpx на httpx2; на результат тестов и приложение оно не влияет.

## В браузере

Проверен реальный интерфейс через локальный сервер:

1. Создание из слабой демо-идеи.
2. Получение 9 вопросов локального Sana Bot.
3. Ручное подтверждение слабой карточки: 10/100.
4. Редактирование и вставка явно помеченных синтетических ответов.
5. Подтверждение: 100/100, Gold Challenge, +350 Coins, +290 XP, 3 коробки.
6. Открытие коробки: Spotlight на 24 часа; score остался 100.
7. Публикация и доступность задачи в каталоге.
8. Переключение Student и отправка идеи, плана, срока и ссылки.
9. Переключение Business, ручной Select.
10. Подтверждение этапа «Прототип» с описанием принятого результата.
11. CyberCats получил 100 XP.
12. Перезагрузка финальной сборки и фильтр Idea: задача 10/100 остаётся доступной.

В журнале браузера на пройденном сценарии ошибок JavaScript не обнаружено. Визуально проверены каталог, редактор и Level Up в доступном окне браузера. Отдельная матрица устройств не проводилась; CSS содержит адаптивные состояния.

## Границы проверки

Настоящий запрос к OpenAI не отправлялся: пользователь не предоставил API-ключ. Контракт проверен имитацией ответов; демонстрационный сценарий пройден на mock. Скрипт установки для чистой машины не запускался целиком — зависимости установлены, сборка, API и интерфейс проверены в рабочем окружении. Нагрузочное и production security-тестирование не проводилось; это локальный хакатон-MVP.

В архив не включаются рабочая база, секреты, node_modules, виртуальное окружение и кеши. При первом запуске создаётся чистый набор 5/5/5; локально в открытом превью могут оставаться записи браузерной проверки.
