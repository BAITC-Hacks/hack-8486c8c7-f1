# TaskQuest AI

## 1. Название проекта

**TaskQuest AI**

MVP для кейса **AI Sana Challenge Hub**.

---

## 2. Краткое описание

TaskQuest AI — платформа, которая помогает бизнесу превращать сырые идеи и проблемы в понятные задачи для студенческих команд.

Бизнес описывает свою идею, а **Sana Bot** анализирует её и задаёт уточняющие вопросы. После заполнения система создаёт карточку задачи и рассчитывает её готовность по шкале от 0 до 100.

Студенты могут просматривать опубликованные задачи, выбирать интересные и отправлять свои предложения. Финальный выбор команды всегда делает бизнес.

---

## 3. Что реализовано

В проекте реализованы:

- создание и редактирование бизнес-задач;
- Sana Bot, который задаёт минимум 3 уточняющих вопроса;
- формирование карточки задачи из ответов;
- ручное подтверждение карточки перед публикацией;
- рейтинг готовности задачи от 0 до 100;
- подсказки о недостающей информации;
- каталог опубликованных задач;
- поиск, фильтры и сортировка задач;
- режимы **Business** и **Student** без регистрации;
- отправка предложений студенческими командами;
- ручной выбор или отклонение команд бизнесом;
- подтверждение этапов работы выбранной команды;
- сохранение данных в SQLite.

Также реализованы элементы геймификации:

- **Challenge Evolution** — визуальное отображение уровня готовности задачи;
- **Sana Coins** — внутренняя валюта платформы;
- **XP** — система прогресса;
- **Achievements** — достижения задачи;
- **Quest Shop** — магазин косметических улучшений;
- **Spotlight** — временное выделение задачи в каталоге.

Quest Shop не влияет на рейтинг задачи. Sana Coins нельзя использовать для покупки или повышения Task Readiness.

### Рейтинг задачи

Задача получает рейтинг от 0 до 100:

- **0–39** — Idea
- **40–69** — Builder
- **70–89** — Launch Ready
- **90–100** — Gold Challenge

Рейтинг зависит от того, насколько полно бизнес описал контекст, данные, ожидаемый результат, критерии успеха, ограничения, пользователей и способ связи.

При достижении новых уровней Challenge Evolution бизнес может получать Sana Coins и XP.

## 4. Как работает решение

Основной сценарий:

1. Бизнес вводит краткое описание своей идеи или проблемы.

2. Sana Bot анализирует описание и задаёт минимум 3 уточняющих вопроса.

3. Бизнес отвечает на вопросы.

4. Ответы добавляются в редактируемую карточку задачи.

5. Бизнес проверяет и подтверждает информацию.

6. Система рассчитывает Task Readiness от 0 до 100.

7. После подтверждения бизнес публикует задачу.

8. Задача появляется в общем каталоге.

9. Студент выбирает интересную задачу и отправляет предложение: идею, план, срок и при необходимости ссылку на прототип.

10. Бизнес просматривает предложения и вручную выбирает или отклоняет команды.

11. Для выбранной команды бизнес может подтверждать выполненные этапы работы.

12. За подтверждённые этапы студенческая команда получает XP.

13. По мере повышения Task Readiness задача проходит уровни **Challenge Evolution**: Idea → Builder → Launch Ready → Gold Challenge.

14. Sana Coins можно использовать в **Quest Shop** для косметического оформления задачи и Spotlight.

Косметические улучшения не изменяют Task Readiness и не дают преимуществ при выборе студенческих команд.

- Python

- SQLite

## 6. Архитектура проекта

Проект разделён на frontend и backend.

### Frontend

Frontend отвечает за:

- интерфейс приложения;
- каталог задач;
- поиск, фильтры и сортировку;
- создание и редактирование задач;
- отображение Task Readiness;
- Challenge Evolution;
- отклики студенческих команд;
- кабинеты Business и Student;
- управление командами;
- Quest Shop;
- отображение Sana Coins и XP.

### Backend

FastAPI отвечает за:

- REST API;
- работу с AI;
- расчёт Task Readiness;
- уровни Challenge Evolution;
- начисление Sana Coins и XP;
- покупки в Quest Shop;
- обработку откликов команд;
- выбор и отклонение команд;
- подтверждение этапов работы;
- валидацию данных;
- работу с SQLite.

### Основная структура

```text
backend/

  app/main.py       REST API и основные сценарии
  app/models.py     валидация данных
  app/scoring.py    расчёт Task Readiness
  app/game.py       Sana Coins, XP и Challenge Evolution
  app/ai.py         OpenAI и локальный fallback
  app/db.py         работа с SQLite
  app/seed.py       демо-данные

  tests/            тесты

frontend/

  src/main.jsx      основное приложение
  src/Catalog.jsx   каталог и фильтры
  src/forms.jsx     формы
  src/Detail.jsx    карточка задачи
  src/Workspace.jsx кабинет
  src/ui.jsx        UI-компоненты
  src/styles.css    стили

docs/

  SPEC.md           исходное ТЗ
  DEMO.md           демо-сценарий
  AI.md             описание AI

start.ps1           запуск на Windows
```

## 7. Установка и запуск

### Требования

- Python 3.11+
- Node.js 20.19+ или 22.12+
- npm

### Windows

Откройте PowerShell в папке проекта и выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

Скрипт автоматически:

1. создаст виртуальное окружение Python;
2. установит backend-зависимости;
3. установит frontend-зависимости;
4. соберёт frontend;
5. запустит FastAPI.

После запуска откройте:

`http://127.0.0.1:8000`

Для остановки приложения нажмите `Ctrl+C`.

### macOS / Linux

```bash
python3 -m venv .venv

.venv/bin/python -m pip install -r backend/requirements.txt

npm ci --prefix frontend

npm run build --prefix frontend

.venv/bin/python -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000
```

После запуска откройте:

`http://127.0.0.1:8000`

## 8. Как проверить решение

Жюри может проверить проект по следующему сценарию:

1. Открыть приложение.

2. Перейти в режим **Business**.

3. Создать задачу с коротким и неполным описанием.

4. Получить уточняющие вопросы от Sana Bot.

5. Ответить на вопросы и проверить сформированную карточку.

6. Подтвердить информацию.

7. Проверить рассчитанный Task Readiness.

8. Посмотреть уровень задачи в Challenge Evolution.

9. Опубликовать задачу.

10. Перейти в режим **Student**.

11. Найти опубликованную задачу в каталоге.

12. Выбрать одну из демо-команд.

13. Отправить предложение для выбранной задачи.

14. Вернуться в режим **Business**.

15. Открыть кабинет и просмотреть полученный отклик.

16. Нажать **Select** или **Reject**.

17. Для выбранной команды подтвердить один из этапов работы и проверить начисление XP.

18. Проверить баланс Sana Coins и XP.

19. Использовать Sana Coins в Quest Shop для покупки косметического оформления или Spotlight.

20. Убедиться, что покупка в Quest Shop не изменяет Task Readiness.

## 9. Данные и интеграции

Для демонстрации используются синтетические данные.

При первом запуске создаются:

- 5 бизнес-задач;
- 5 студенческих команд;
- 5 откликов;
- стартовый демо-баланс Sana Coins и XP.

Данные сохраняются в SQLite.

Для AI используется **OpenAI Responses API**. API-ключ хранится только на backend и не должен публиковаться в GitHub.

Для настройки OpenAI можно создать `.env` в корне проекта:

```env
OPENAI_API_KEY=ваш_ключ
OPENAI_MODEL=gpt-4o-mini
```

Без API-ключа используется локальный Sana Bot.

## 10. Ограничения

Текущая версия является MVP для хакатона.

В проекте нет:

- полноценной регистрации и авторизации;
- чата;
- уведомлений;
- файлового хранилища;
- автоматического назначения команд.

Режимы Business и Student являются демонстрационными и не используются как полноценная система авторизации.

Все демонстрационные компании, команды, задачи и отклики используют синтетические данные.

По умолчанию приложение запускается локально на `127.0.0.1`.

## 11. Последние изменения

В актуальной версии интерфейс и система геймификации были упрощены.

Из проекта удалены:

- **Mystery Box**;
- отдельная вкладка **«Квесты и награды»**;
- квесты бизнес-задач;
- студенческие квесты;
- квестовые награды;
- случайные награды за достижение уровней.

Сохранены:

- **Challenge Evolution** — визуальное отображение уровня готовности задачи;
- **Sana Coins** — внутренняя валюта платформы;
- **XP** — отображение прогресса;
- **Achievements** — достижения задачи;
- **Quest Shop** — магазин косметических улучшений;
- **Spotlight** — временное выделение задачи в каталоге.

После изменений геймификация стала проще и не отвлекает от основного сценария платформы: превращения бизнес-идеи в качественную задачу и взаимодействия бизнеса со студенческими командами.

Task Readiness по-прежнему рассчитывается только на основе полноты подтверждённой бизнесом карточки. Его нельзя увеличить с помощью Sana Coins, XP или покупок в Quest Shop.
