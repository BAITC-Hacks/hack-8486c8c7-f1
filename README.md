# TaskQuest AI

Запускаемый MVP для **AI Sana Challenge Hub**: бизнес превращает сырую идею в понятную задачу, студенты предлагают решения, бизнес вручную выбирает команды.

**React + Tailwind CSS + FastAPI + SQLite.** Без API-ключа работает весь сценарий через локальный Sana Bot. Интерфейс на русском. Исходное ТЗ: [docs/SPEC.md](docs/SPEC.md).

## Быстрый запуск

Требования: **Python 3.11+**, **Node.js 20.19+ или 22.12+**, npm. Для установки нужен интернет. После установки и сборки mock-демо работает без интернета.

### Windows — один скрипт

Откройте PowerShell в папке проекта:

    powershell -ExecutionPolicy Bypass -File .\start.ps1

Скрипт создаёт локальную .venv, устанавливает зависимости, собирает интерфейс и запускает приложение. Откройте **http://127.0.0.1:8000**. Остановка: Ctrl+C. Скрипт не меняет постоянную execution policy системы.

### Windows — вручную

    py -3 -m venv .venv
    .\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
    npm.cmd ci --prefix frontend
    npm.cmd run build --prefix frontend
    .\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000

### macOS / Linux

    python3 -m venv .venv
    .venv/bin/python -m pip install -r backend/requirements.txt
    npm ci --prefix frontend
    npm run build --prefix frontend
    .venv/bin/python -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000

После сборки FastAPI обслуживает и API, и React: нужен только один сервер. В архив включён готовый frontend/dist, поэтому для **просмотра без изменения интерфейса** достаточно Python, установки backend-зависимостей и последней команды; Node нужен для пересборки.

### Разработка

Терминал 1:

    .\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --reload --port 8000

Терминал 2:

    npm.cmd run dev --prefix frontend

Откройте http://127.0.0.1:5173. Vite перенаправляет /api на порт 8000. Все команды выполняются из корня проекта.

## Что работает

- Сырая идея → Sana Bot задаёт минимум 3 вопроса по разным полям.
- Ответы напрямую формируют редактируемую карточку. Обязательный checkbox ручного подтверждения.
- Серверный readiness 0–100, детализация и список недостающих сведений.
- Подтверждение → публикация отдельным действием → открытый каталог.
- Сортировка по readiness или новизне, поиск, фильтры по теме и уровню.
- Все опубликованные задачи, включая 0–39, доступны для откликов.
- Business / Student без регистрации. В Student можно выбрать одну из 5 демо-команд.
- Отклик: команда, идея, план, срок, необязательная http(s)-ссылка на прототип.
- Бизнес сравнивает отклики и вручную нажимает Select / Reject; можно выбрать несколько или ни одной команды.
- Подтверждённый этап выбранной команды приносит XP; число откликов не ограничивается.
- Sana Coins, XP, одноразовые квесты, достижения, Level Up, Mystery Box, магазин оформления, Spotlight 24 часа, Challenge Evolution.
- Изменения и награды сохраняются в SQLite между перезапусками.

## Формула рейтинга

До подтверждения карточки — 0. Сервер рассчитывает баллы сам; клиент не может передать score или награду.

| Раздел | Баллы | Условие MVP |
|---|---:|---|
| Контекст и потребность | 20 | По 10 за контекст и потребность |
| Данные и материалы | 20 | Данные, примеры или источники описаны |
| Ожидаемый результат | 15 | Описан результат |
| Критерии успеха | 15 | Описание содержит числовую цель |
| Ограничения | 10 | Описаны сроки, доступы или другие границы |
| Пользователи | 10 | Указаны пользователи |
| Связь с бизнесом | 10 | Контакт 4 + консультации 3 + обратная связь 3 |
| **Итого** | **100** | |

ТЗ задаёт веса и смысл критериев, но не алгоритм семантической проверки. Здесь используется **явная эвристика полноты**: минимум 12 символов после trim в основных полях, 5 в пользователях, 3 в контакте, 8 в консультациях и обратной связи. Для критериев дополнительно нужна цифра. Строки «не знаю», «уточним позже», «нет информации», «не определено» дают 0. Эвристика не доказывает качество текста или валидность метрики; бизнес подтверждает содержание вручную. Код: backend/app/scoring.py.

- 0–39: **Idea**
- 40–69: **Builder**
- 70–89: **Launch Ready**
- 90–100: **Gold Challenge**

При удалении сведений рейтинг снижается. Исторические достижения остаются, текущий уровень и позиция зависят от текущего рейтинга. При равном readiness выше новая задача. Spotlight — отдельный блок, не меняющий сортировку общего каталога.

## Экономика

Квесты выдаются один раз на конкретную задачу после подтверждения полного раздела:

| Квест | Coins | XP |
|---|---:|---:|
| Story Builder | 20 | 20 |
| Data Hunter | 30 | 20 |
| Outcome Maker | 20 | 20 |
| Make It Measurable | 30 | 20 |
| Set the Rules | 15 | 20 |
| People First | 15 | 20 |
| Stay Connected | 20 | 20 |
| Student Friendly — ответы на все сохранённые вопросы | 25 | 30 |
| Достигнуть 40 | 25 | 40 + 1 box |
| Достигнуть 70 | 50 | 40 + 1 box |
| Достигнуть 90 | 100 | 40 + 1 box |

Удаление/повторное заполнение поля и повторное сохранение не позволяют повторно получить награду. Переход 0→100 даёт все три награды уровня.

Магазин: **50** — неоновая рамка, **100** — Spotlight на 24 часа, **150** — Aurora Skin. Коробка не продаётся: выдаётся за новый порог. Награда: ещё не открытая рамка, Aurora, Pixel Badge или Spotlight. Выбор равновероятный из доступных вариантов. Повторный Spotlight обновляет срок до 24 часов от открытия, а не суммируется. Косметика применяется сразу. Реальных платежей нет, Coins не покупают score.

Студенты: исследование **50 XP**, прототип **100 XP**, передача результата **150 XP**. Только Business подтверждает этап с описанием проверенного результата. Один этап награждается один раз на пару задача–команда, даже при нескольких откликах. Уровень команды: 1 + floor(XP / 200). Отклики, Select и Reject сами по себе XP не дают.

SQLite-транзакции BEGIN IMMEDIATE защищают баланс, коробки и XP. У карточек version-check: HTTP 409 при конфликте редактирования.

## AI / Sana Bot

Скопируйте .env.example в .env **в корне проекта**. Без ключа ничего настраивать не нужно.

    OPENAI_API_KEY=ваш_ключ
    OPENAI_MODEL=gpt-4o-mini

Ключ читается только сервером. Модель можно заменить через env на доступную вашему аккаунту модель с поддержкой Structured Outputs.

AI анализирует описание и задаёт вопросы по недостающим полям. Он **не генерирует ответы**, не меняет данные бизнеса, не начисляет баллы и не выбирает команды. Ответы бизнеса переносятся в поля без переписывания. Для полного брифа бот уточняет данные, критерии и ограничения.

Промпт и контракт: [docs/AI.md](docs/AI.md), backend/app/ai.py. Используется [OpenAI Responses API / Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs), store: false. Таймаут — 20 секунд. Сбой сети, ошибка API, отказ, обрезанный ответ, неверный JSON, менее 3 вопросов, повторы полей или нарушение схемы → локальный fallback с уведомлением.

Режим виден в редакторе. Реальный вызов требует действительного ключа; mock и тесты не требуют его.

## Демо-данные

Первый запуск создаёт 5 исходных описаний и карточек с рейтингами **100, 70, 65, 40, 10**, 5 команд и 5 откликов. Компании, контакты и сведения синтетические; example.com-ссылки обозначают демо-прототипы.

Стартовые **180 Coins, 120 бизнес-XP и 1 box у первой задачи** — заданный демонстрационный баланс. Квесты существующих карточек отмечены полученными. Команды начинают с 0 XP.

База: backend/data/taskquest.db, не входит в архив. Для чистого состояния остановите сервер и **переименуйте** файл в taskquest.backup.db; следующий запуск создаст новый набор. Можно задать отдельный DATABASE_PATH в .env.

## Проверка

    .\.venv\Scripts\python.exe -m pytest backend/tests -q
    npm.cmd run build --prefix frontend

API-документация: http://127.0.0.1:8000/docs. Health: /api/health.

Тесты покрывают веса, уровни, подтверждение, сквозной сценарий, низкий рейтинг, неограниченные отклики, выбор нескольких команд, повторные награды, этапы и XP, косметику, роли, невалидные URL, версии и ответы AI. Результаты: [docs/VERIFICATION.md](docs/VERIFICATION.md).

## Границы MVP

Демо-роли намеренно не являются аутентификацией. Все бизнес-задачи находятся в общем кабинете, отклики видны демо-участникам. Для публичного сервиса с реальными данными потребуются авторизация, разграничение доступа и защита API. По умолчанию сервер слушает только 127.0.0.1.

Нет регистрации, чата, уведомлений, файлового хранилища и автоматического назначения команд — согласно объёму ТЗ. Ссылку на прототип открывает браузер; сервер её не загружает. Если порт 8000 занят, остановите старую копию приложения или задайте другой --port; в разработке также измените proxy в frontend/vite.config.js.
